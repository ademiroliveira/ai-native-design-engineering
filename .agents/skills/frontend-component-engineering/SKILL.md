# Frontend Component Engineering

Build reusable, composable components aligned with existing repository conventions.

Model state explicitly, keep APIs understandable, preserve type safety, and avoid unnecessary dependencies. Consider loading, empty, error, success, disabled, and responsive states as part of component behaviour.

Keep component boundaries driven by cohesion and reuse, not by a desire to maximize abstraction.
