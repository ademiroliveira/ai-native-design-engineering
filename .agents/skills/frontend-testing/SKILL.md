# Frontend Testing

Use the repository's existing testing strategy first.

Test behaviour and user-visible outcomes, especially critical states and regressions. Prefer stable selectors and meaningful assertions.

Use existing visual-regression tests where available, but do not add new testing or screenshot infrastructure unless the feature needs it and the repository lacks an appropriate capability.
