# Agentic UI Patterns

When interfaces involve AI or agents, design the interaction as a system rather than a chat surface alone.

Make intent, context, system state, capability, action, feedback, uncertainty, permissions, and recovery visible where useful.

Distinguish generated suggestions from committed actions. Keep consequential actions reviewable and reversible where possible. Make it clear what the system did, what it recommends, and what still requires human approval.
