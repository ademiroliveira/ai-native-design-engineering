# Interaction Design

Design behaviours and states, not only static screens.

Consider default, loading, empty, error, success, disabled, partial, interrupted, and recovery states where relevant.

For each important interaction define the trigger, system response, feedback, next action, and failure or recovery behaviour. Keep the model as lightweight as the feature permits.
