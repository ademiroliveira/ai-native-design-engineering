# Design to Code

Translate design intent into reusable frontend implementation.

Do not copy pixels blindly. Infer layout rules, component boundaries, responsive behaviour, interaction states, and token usage. Treat Figma, screenshots, specs, and existing UI as context sources rather than automatic specifications.

Inspect the host repository before implementation, then validate the result against the intended outcome and available evidence.
