# Visual QA

Review the rendered interface rather than source code alone.

Check hierarchy, spacing, alignment, typography, states, responsive behaviour, component consistency, accessibility, and obvious regressions. Compare against available design evidence and record observations separately from assumptions.

Prioritise issues by user impact and confidence. Do not recommend visual changes merely for personal preference.
