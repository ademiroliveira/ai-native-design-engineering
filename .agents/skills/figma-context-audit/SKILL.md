# Figma Context Audit

Use Figma when it is available, but never require it.

Extract useful context: user flow, component intent, layout rules, design tokens, states, responsive behaviour, and unresolved decisions. Treat Figma as one source among product briefs, existing UI, screenshots, specs, and code.

If Figma or its MCP integration is unavailable, continue using the strongest available context sources and record what is missing.
