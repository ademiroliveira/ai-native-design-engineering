# Tooling Matrix

The methodology is capability-first. Specific tools are adapters.

| Capability | Minimum viable source | Optional integrations |
|---|---|---|
| Product context | briefs, docs, repo | research/knowledge MCP |
| Design context | existing UI, specs, screenshots | Figma MCP |
| Design system | components, tokens, Storybook | design-system MCP |
| Implementation | repo + terminal | coding agents |
| Browser evidence | browser + screenshots | Playwright/browser MCP |
| Quality | tests + review checklist | visual regression tooling |

Figma MCP is useful but not foundational. The workflow must remain viable in enterprise environments where MCP access is restricted.
