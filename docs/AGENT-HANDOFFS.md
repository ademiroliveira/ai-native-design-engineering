# Agent Handoffs

The agents form a lightweight workflow rather than an autonomous chain.

1. **Product Design** — frames intent, users, flows, states and acceptance criteria.
2. **Design Engineer** — turns design decisions into component/layout implementation decisions.
3. **Frontend Engineer** — implements maintainable production code.
4. **UI Quality** — verifies the rendered outcome and identifies regressions.

Each handoff should carry:
- objective and user outcome
- relevant context
- decisions already made
- assumptions and unknowns
- acceptance criteria
- evidence available
- unresolved questions

Human review remains the decision boundary for consequential product choices and external actions.
